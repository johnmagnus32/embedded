# gb2 enclosure (code-CAD, build123d)

The shell is generated by Python from the KiCad board, so it follows the board when the board changes.

| File | What it does |
|---|---|
| `export_board.py` | KiCad → `build/board.json`: board outline + holes, every part's courtyard and body height (from its 3D model), the GBA silhouette, 2090 module / battery / speaker / LRA envelopes (from `pcb/gb2/draw_mech.py`). Run with **KiCad's python**. |
| `params.py` | Frame, constants, context geometry (board, parts, 2090, battery, speaker, LRA) and the shared contracts every module builds against. |
| `shell.py` | The two bare shells (GBA silhouette slab, hollowed, split at the board top). |
| `front_features.py` | The front shell's features from `front_screen.py` (screen opening, lens pocket, LED, grille), `front_keys.py` (face holes, guide tubes) and `front_struct.py` (bosses, J1 hatch, board locators). |
| `back_openings.py` | The back shell's features (bosses, battery fence, speaker cradle, posts, locator pockets) and the wall openings (edge keys, power slot, USB-C). |
| `controls.py` | The printed controls: D-pad + washer, A, B, Start, Select, Vol±, L, R, power slider. |
| `enclosure.py` | Assembles everything. Writes `out/<part>.stl` / `.3mf` (print poses), `out/assembly.step`, `out/lens.dxf` / `.svg`, and pushes to the live viewer. Run with **`.venv/bin/python`**. |
| `checks.py` | The fit checks (`DESIGN.md` section 6). |

## Setup (once)

```sh
/opt/homebrew/bin/python3.13 -m venv .venv
printf '[global]\nindex-url = https://pypi.org/simple\n' > .venv/pip.conf   # this venv only: public PyPI
.venv/bin/pip install -r requirements.txt
```

The `.venv/pip.conf` line points **only this virtualenv** at public PyPI; the user-level pip config (the internal
mirror) is untouched. VS Code extension: **OCP CAD Viewer** (`bernhard-42.ocp-cad-viewer`).

## Use

```sh
# after any board change
/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3 export_board.py
# build / export / view, then check
.venv/bin/python enclosure.py
.venv/bin/python checks.py          # --fast skips the 2-minute assembly sweep
```

To see it live, open this folder as its own VS Code window - `code projects/gameboy-v2/enclosure` - and open
`enclosure.py`: `.vscode/settings.json` selects `.venv` as the interpreter, so the OCP CAD Viewer starts by itself
(port 3939). Every run of `enclosure.py` re-sends the model. Print from `out/*.3mf` (or `.stl`) in your slicer.

## Frame and conventions

Board mm, +X right, **+Y up** (KiCad's Y is flipped), Z up; the board's bottom face is z = 0, its top z = 1.6.
Every shared number is a named constant in `params.py`; `DESIGN.md` explains each one.
